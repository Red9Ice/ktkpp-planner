# Интеллектуальная система составления и управления расписанием КОГПОАУ КТКПП
*(Solver + Cloud-боты)*

Система автоматической генерации базового семестрового расписания и оперативного управления заменами для колледжа **КОГПОАУ КТКПП** (45 учебных групп, 1–4 курсы), построенная на базе **Google OR-Tools (CP-SAT)** и **Serverless/Cloud** архитектуры (100% бесплатный стек).

---

## 🌟 Ключевые особенности и адаптация под структуру КТКПП

- 🧠 **Математический решатель CP-SAT (Google OR-Tools):**
  - **45 реальных групп** колледжа (`С`, `ОС`, `ИС`, `АП`, `ТХ`, `З`, `Т`, `ТД`, `ТК`, `ГД`, `ПД`, `ТМ`).
  - **5-дневная учебная неделя:** Понедельник — Пятница, от 1 до 6 пар в день.
  - **Непрерывность расписания (Contiguity) на уровне подгруппы:** никаких окон внутри учебного дня подгруппы (реализовано через `AddAutomaton`).
  - **Старт дня:** занятия начинаются строго с 1-й, 2-й или 3-й пары (`start <= 3`).
  - **Окончание дня:** не позже 6-й пары с мягким штрафом за 6-ю пару.
  - **Спортзал (`С/з`):** поддержка одновременных занятий до 3 групп/подгрупп.
  - **Фиксированные слоты:** «Разговоры о важном» строго на 1-й паре понедельника для 1-го курса, «Классный час» для старших курсов.
  - **Синхронизация лекций и лабораторных:** поддержка `whole_group` (лекции) и `split` (лабораторные параллельно или со сдвигом).
  - 3 режима работы: **Full Generation** (с нуля), **Repair** (точечные правки), **Incremental Replacement** (быстрый подбор замены преподавателя).

- ☁️ **Бесплатный облачный стек (Без собственного сервера 24/7):**
  - **База данных:** Бесплатный PostgreSQL на [Supabase](https://supabase.com/) или [Neon.tech](https://neon.tech/).
  - **Боты 24/7:** Telegram (aiogram 3) и MAX боты на бесплатном PaaS [Render.com](https://render.com/) в режиме Webhooks.
  - **Вычисления Solver:** On-demand в бесплатных раннерах **GitHub Actions** (или на ПК диспетчера).

- 📤 **Мультиформатный экспорт:**
  - **Excel (.xlsx):** сводная сетка расписания КТКПП на 5 дней с объединенными ячейками для лекций и раздельными колонками подгрупп (ПГ.1 и ПГ.2).
  - **PDF (.pdf):** готовые к печати альбомные сетки расписания для каждой группы.
  - **Чат-боты:** форматированный текстовый вывод с разделением по подгруппам без ложных "окон".

## 📂 Структура проекта

```
KTKPP PLANNER/
├── .github/workflows/
│   └── run_solver.yml          # GitHub Actions workflow для облачного запуска Solver
├── config/
│   └── settings.py             # Конфигурация под КТКПП через pydantic-settings
├── data/
│   ├── migrations/
│   │   └── 001_initial_schema.sql  # Схема PostgreSQL (Supabase/Neon)
│   └── samples/
│       ├── ktkpp_data.json     # Полный эталонный датасет КТКПП (45 групп, 49 кабинетов)
│       └── sample_data.json    # Компактный тестовый датасет для быстрых тестов
├── docs/
│   ├── TZ.md                   # Техническое задание
│   └── DEPLOYMENT.md           # Инструкция по бесплатному развертыванию
├── src/
│   ├── bot/
│   │   ├── core/service.py     # Общая бизнес-логика для ботов
│   │   ├── telegram/bot.py     # aiogram 3 Telegram-бот (команды /schedule ИС-11)
│   │   ├── max/bot.py          # Адаптер MAX Messenger
│   │   └── server.py           # FastAPI вебхук-сервер для Render.com
│   ├── db/
│   │   ├── models.py           # SQLAlchemy ORM модели
│   │   └── session.py          # Подключение к БД и сессии
│   ├── exporters/
│   │   ├── excel_exporter.py   # Генерация .xlsx с объединенными ячейками на 5 дней
│   │   ├── pdf_exporter.py     # Генерация .pdf для печати
│   │   └── text_exporter.py    # Форматирование для мессенджеров
│   └── solver/
│       ├── contiguity.py       # AddAutomaton для непрерывности и start <= 3
│       ├── model.py            # CP-SAT математическая модель с учетом С/з и фикс-слотов
│       ├── repair.py           # Модуль замен (Incremental replacement)
│       └── runner.py           # Консольный запуск Solver'а
├── tests/
│   └── test_solver.py          # Автоматические тесты ограничений и решателя
├── requirements.txt            # Зависимости Python
└── README.md
```

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск Solver'а на данных КТКПП
```bash
python -m src.solver.runner --dataset data/samples/ktkpp_data.json --mode full --export-excel College_Timetable.xlsx
```

### 3. Локальный запуск ботов и сервера вебхуков
```bash
uvicorn src.bot.server:app --reload --port 8000
```
